Built with [Astro 6](https://astro.build), designed using Claude Code, [Paper](https://paper.design/) and [DaisyUI v5](https://daisyui.com). Content is authored in markdown using typed content collections. The hero background is a real-time interactive ASCII field rendered with [textmode.js](https://code.textmode.art), a WebGL2 creative coding library — the plasma reacts to cursor position. An email newsletter is currently under development. The source is [open on GitHub](https://github.com/vikramrojo/vikram.rojos.us).
