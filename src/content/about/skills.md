I run agent loops between Claude and Mimo on a dedicated machine — Claude for project planning, Mimo for development and review. Claude Design handles discovery and early exploration; whatever survives gets hardened into a real design system in Figma. I work spec-first with OpenSpec and put every implementation through extensive QA before it moves. Latest builds run on VMs I host myself, and production ships to Cloudflare.

Most of the leverage comes from two scaffolds I maintain — a TanStack, Cloudflare, Flue, and Capacitor stack for web, and a Swift scaffold for iOS — each assembled from the skills and MCP servers relevant to that kind of work. It's the same setup behind Postbyte, and it means an early prototype now takes a weekend to a week.
